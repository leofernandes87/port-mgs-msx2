# Conteúdo local

Conteúdo desta pasta é ignorado, exceto este documento. Não adicionar arquivos protegidos ao Git. ROMs originais devem ser tratadas somente para leitura; nenhuma está incluída.

- `en-eu-rc750/`: única origem consumida pelo Godot e pelas ferramentas; todo arquivo leva `rom_profile = en-eu-rc750` e o SHA-256 canônico.
- `legacy-jp-rc750-local/`: dados antigos derivados do dump japonês, preservados apenas para o relatório de diferenças (`tools/reverse_engineering/compare_regions.py`). Não são aceitos pelo Godot.
